# Personal Portfolio Website — Zishan Zaffar

A responsive personal portfolio website built with semantic **HTML5** and custom **CSS3**. Created as part of a B.Tech CSE Core Web Development assignment, this project showcases personal background, technical skills, featured projects, and an interactive contact form.

## Features

* **Sticky Navigation Bar:** Smooth-scrolling navigation menu with hover transitions linking directly to the **About**, **Skills**, **Projects**, and **Contact Form** sections.
* **About Section:** A two-column CSS Grid layout introducing the developer alongside a styled circular profile picture.
* **Skills Table:** A structured HTML table highlighting current proficiency levels across core web technologies (**HTML**, **CSS**, and **JavaScript**).
* **Project Showcase:** Dedicated gallery section displaying project previews (`1.png` and `2.png`) with interactive hover scaling effects.
* **Validated Contact Form:** Includes client-side HTML5 form validation (`pattern`, `minlength`, `maxlength`, `min`, `max`, and `required` attributes) for:
  * Name (alphabetical characters only)
  * Password (6–10 characters)
  * Gender selection (radio buttons)
  * Date of Birth (restricted date range)
  * Indian 10-digit mobile number validation (`[6-9]{1}[0-9]{9}`)
  * Email address & Country dropdown
  * Feedback textarea & Terms acceptance checkbox
  * Styled **Submit** and **Reset** buttons
* **Floating Back-to-Top Button:** Fixed bottom-right button for quick navigation back to the top of the page.
* **Footer & Social Links:** Includes copyright details and external social media links (Instagram, Facebook, Snapchat, and LinkedIn).

## Technologies Used

* **HTML5:** Semantic structure (`<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`), accessible ARIA labels, tables, and form controls.
* **CSS3:** Custom styling (`style1.css`) utilizing Flexbox, CSS Grid, sticky/fixed positioning, keyframe-style hover transitions, box shadows, and a dark navy/blue color palette (`#011627`, `#013a63`, `#116FAB`).


## How to Run Locally

1. Clone or download this repository to your local machine.
2. Ensure all image assets (`Image.JPG`, `1.png`, `2.png`) and `style1.css` are in the same root directory as your HTML file.
3. Open `index.html` in any modern web browser (Chrome, Firefox, Edge, or Safari).
